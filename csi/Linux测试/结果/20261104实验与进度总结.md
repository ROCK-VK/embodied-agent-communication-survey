# 实验与项目进度

进度整理日期：2026 年 11 月 7 日。

## 科研目标与当前进度

目标是在机器狗运动、上传真实视觉与激光雷达数据时，把样本和采集时间、机器人位置、实际无线数据帧与接收端 CSI 关联起来。不能假设一帧传感器数据等于一个 UDP 包、一个无线帧或一条 CSI。

当前已做到：真实 RGB 图像和部分雷达数据经 Jetson Wi-Fi 上传，部分数据分片能通过实际无线 MPDU 精确关联 CSI；机器狗位置、传感器原始采集时间及实时完整闭环尚未打通。不宜给整个科研目标编造一个完成百分比；以下按环节衡量。

| 环节 | 状态与限制 |
|---|---|
| UDP 包 → 无线帧 → CSI | 已在测试包和真实样本分片上实现精确匹配，覆盖不完整 |
| 真实视觉、雷达数据 → 分片和包 | 真实 RGB 缓存图像及 5 个雷达数据包上传并完整重组；不是同步 RGB/Depth 帧或完整雷达扫描 |
| 分片 → CSI | 两次发送后的 RGB 66/79、雷达 17/18 个分片至少匹配一条 CSI；其他分片没有匹配证据 |
| 机器狗位置 | 本次未取得；原因未确认。低频状态主题是待验证线索 |
| 采集时间与时钟 | 图像曝光时间未知、雷达时钟域未知、跨设备误差未量化；首包上传与图像缓存请求相隔约 197 秒，不是近实时上传 |
| 运动研究与稳定性 | 一次人体活动对照有变化；机器狗运动、长期稳定性及重复性尚未验证 |

## 已完成的实验

1. 测试包帧级验证：60 个唯一 UDP ID 全部被接收；独立无线抓包解密 52 个，其中 46 个的 MPDU 与各自 CSI 记录逐字节相同，CSI 结构检查通过。三种载荷各 20 包也有成功匹配。后续从 CSI 记录内直接提取并解密 MPDU，复现此前两轮全部 93 条匹配。
2. CSI 物理初检：非零且结构合格的复数数据，以及一次静止—人体活动—恢复静止对照，活动候选窗口幅度波动上升、恢复后接近基线。窗口为人工近似标记，不能证明因果或重复性；完整官方解析器与相位物理准确性仍待核验。
3. 连续采集：固定 48 字节 UDP 负载，5、10、20 包/秒各约 60 秒。应用层接收全部成功；可精确关联 CSI 的比例在 52.9%–69.3% 之间，且各 10 秒窗口有明显波动。
4. 静止真实样本：RGB 图像、5 个雷达包及元数据分片均重组成功；212 个不同 packet_id 均被应用接收，其中 138 个精确关联 CSI，全部与独立 PCAP MPDU 唯一字节一致。图像 94/158 包、雷达 29/36 包、元数据 15/18 包成功关联。每个分片发送两遍，故分片覆盖和包覆盖分母不同。Go2 位置未取得。

## 稳定性与每秒 CSI：如何衡量

两个都重要，但不是同一指标。研究关联可靠性时，先确保匹配准确、CSI 质量可用、随时间覆盖稳定，再看是否有足够的有效关联速率；达到任务所需时间分辨率之后，单纯增加总 CSI 条数并不一定增加有用数据。

| 指标 | 定义及意义 | 本次情况 |
|---|---|---|
| 匹配准确性 | packet_id、无线 MPDU 和 CSI 是否有帧级证据 | 连续测试 1214 条 CSI 匹配均与唯一 PCAP MPDU 字节一致；真实样本 138/138 同样一致。这是交叉验证，不代表全部可能帧的零误匹配 |
| 有效关联覆盖率 | 成功匹配的不同发送 packet_id / 发送的不同 packet_id | 测试流三档分别 54.3%、69.3%、52.9%；真实样本 138/212，即 65.1% |
| 有效关联速率 | 时间内可精确关联的不同 packet_id 数 / 观察时长 | 按各档约 60 秒估算约 2.7、6.9、10.6 个唯一包/秒；是本次平均值，不是 CSI 总产出能力 |
| 稳定性 | 覆盖率、有效关联速率、间隔、数据质量、丢失及运行状态在时间和重复实验中是否保持可接受 | 三档 10 秒窗口覆盖率范围 32%–87%；每档仅一次约一分钟，尚不足以评估长期稳定性 |
| CSI 总速率 | 全部 CSI 记录 / 采集时长 | 包含背景帧、重试及无法识别业务归属的记录，不能直接当作有效关联速率 |
| 物理质量 | CSI 是否结构正确、数值合理，且对受控变化表现可重复 | 已做结构初检和一次活动对照；完整解析、相位和重复性仍未验证 |

这里的有效关联速率按不同 packet_id 去重，不是唯一 CSI 记录数的通用同义词：一个包可能有多次无线传输、多个 CSI 记录，也可能没有。固定发包速率下统计间隔、缺口和长时间下界，可比只报总体平均值更好反映稳定性。具体最低速率和覆盖阈值应由未来运动速度、所需时间分辨率与容许缺失决定，现阶段没有已验证的统一门槛。

| 测试发送速率 | 发送 / 应用接收 | 成功关联唯一 ID | 覆盖率 | 有效关联平均速率（按约 60 秒估算） |
|---:|---:|---:|---:|---:|
| 5 包/秒 | 300 / 300 | 163 | 54.3% | 约 2.7 包/秒 |
| 10 包/秒 | 600 / 600 | 416 | 69.3% | 约 6.9 包/秒 |
| 20 包/秒 | 1200 / 1200 | 635 | 52.9% | 约 10.6 包/秒 |

三档依次只测一次、背景流量未控制，因此不能断言某个速率在一般情况下最好；应用 100% 接收不等于 100% 有 CSI。仅 PCAP 有的 53 个 ID 未在 CSI 目标帧中找到相同 MPDU；另 833 个 ID 两路径均未恢复，原因未知。

## 优先下一步

先查清 Go2 的位置状态与其坐标系、原始时间戳；同时补全相机、雷达采集标识和时钟，缩短从采集到上传的延迟。然后在静止条件下形成带位置及时间的第一条真实关联记录，再用重复试验衡量覆盖率、有效关联速率、时间间隔与 CSI 质量；满足运动所需时间分辨率后再做受控运动。保留一对多关系，持续记录缺失、重传和重复；不凭时间最近推断帧级匹配。
