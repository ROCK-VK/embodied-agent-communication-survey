在项目根目录的PowerShell运行：

```powershell
& .\下一阶段\复现下一阶段.ps1
```

首次克隆先按[发布与复现说明](../发布说明.md)恢复环境；Docker需启动，复用本项目两套虚拟环境。镜像基础为本地已配置的Noetic镜像；新镜像只安装网络工具。脚本不会修改既有Ubuntu或另外两个Docker项目，结束后停止本阶段3个容器。默认使用已核验的官方正文快照；加`-RefreshOfficialDocs`可重新访问官方资料。

netem计数与计时会随随机丢包、调度变化；复现要求守恒与预期机制通过，不要求毫秒数和缺失序号相同。原始输出、pcap和SQLite文件存放项目根的日志目录，均不上传。可重新生成的图像数据来源及许可见 [数据说明](数据说明与许可.md)。

原阶段的360组合成特征实验与ROS2 QoS验证保留在 [首阶段成果](../README.md)。本阶段验证已完成的A2A任务重启查询；没有完成运行中训练任务故障续跑、原生宇树消息桥接或物理无线测试。
