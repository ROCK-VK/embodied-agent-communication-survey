## 本机复现

已有环境时，在PowerShell中执行：

```powershell
Set-Location ./simulation
& .\复现实验.ps1
```

需要Docker启动，脚本只操作本项目的两个容器。使用已有Python3.13虚拟环境，不修改现有Ubuntu或其他项目；结果文件会按本次实际运行更新，末尾只停止本项目容器。

重建环境先运行 `& .\环境\恢复环境.ps1`；完整版本与单步命令见 [环境说明](环境/环境说明.md)。如本机策略阻止 `.ps1`，可以逐条运行其中命令，不修改全局执行策略。

固定更新次数的结果应可复现；50ms墙钟预算、网络/队列调度和时延会随机器负载变化，因此更新次数和部分异常计数可能变化。脚本保留预算/序号守恒和预期异常断言，不要求重跑得到完全相同的毫秒值。报告由实际CSV/JSON生成，不手填实验数字。

这里是特征与消息机制模拟，不是3D机器人仿真器，也不是Orin NX硬件性能模拟。完美标签、感知模型失配、规则型A2A服务均为明确假设；本轮没有证明任何算法最优，没有真实机器狗或无线链路实测。
